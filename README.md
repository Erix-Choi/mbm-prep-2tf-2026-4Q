# MBM 세션 준비표

11월 MY · PH 세미나 일정과 사람별 준비(Step · 캘린더)를 보는 페이지입니다.

- 페이지: `index.html`
- 자주 바뀌는 내용(업데이트 소식, 행사, 인원별 일정, 할 일): `data.js`

내용 변경은 규완에게 알려주세요.

## 진행 상태 (완료 · 진행 중 · 착수 전)
- 페이지의 업무마다 **상태 바꾸기** 버튼 → 착수 전 / 진행 중(진행률) / 완료(완료일) 저장. 팀 PIN 필요.
- 저장은 구글 시트(Apps Script 웹 앱, `apps-script.gs`)에 쌓이고, 페이지는 열 때와 1분마다 읽어 옴.
- 채팅으로 반영한 상태는 `data.js`의 `status`(at = 반영 시각). 시트 값과 비교해 더 최근 것이 보임.
